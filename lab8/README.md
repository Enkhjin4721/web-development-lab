# Лабораторийн ажил №8
## Bootstrap ба Tailwind CSS

### 1. Зорилго
Bootstrap болон Tailwind CSS ашиглан ижил төрлийн зургийн цомгийн веб хуудас хийж, тэдгээрийн ялгаа, давуу талыг харьцуулах.

### 2. Хийсэн ажил
- Bootstrap ашиглан веб хуудас хийсэн.
- Tailwind CSS ашиглан ижил загварын веб хуудас хийсэн.
- Хоёр хуудсанд responsive grid болон dark mode тохируулсан.
- Киноны зураг, дэлгэрэнгүй мэдээлэл, санал хүсэлтийн форм оруулсан.
- Lighthouse ашиглан веб хуудсуудын үзүүлэлтийг шалгасан.

### 3. Lighthouse онооны харьцуулалт

| Үзүүлэлт | Bootstrap | Tailwind |
|---|---:|---:|
| Performance | 96 | 96 |
| Accessibility | 88 | 95 |
| Best Practices | 100 | 100 |
| SEO | 91 | 91 |

### 4. CSS файлын хэмжээ

| Файл | Хэмжээ |
|---|---:|
| Bootstrap `style.css` | 569 байт |
| Tailwind `output.css` | 13,657 байт |

*Тайлбар: Эдгээр нь зөвхөн төслийн локал CSS файлуудын хэмжээ бөгөөд Bootstrap CDN-ийн CSS файлыг оруулаагүй.*

### 5. Картын class-ийн тоо

| Үзүүлэлт | Bootstrap | Tailwind |
|---|---:|---:|
| Картын үндсэн элементийн class-ийн тоо | 2 | 7 |

### 6. Дүгнэлт
Энэ лабораторийн ажлаар Bootstrap болон Tailwind CSS ашиглан веб хуудас хийж, тэдгээрийг харьцууллаа. Bootstrap нь бэлэн компонент ашиглахад хялбар байсан бол Tailwind CSS нь utility class ашиглан загвараа нарийн тохируулах боломжтой байв. Lighthouse шалгалтаар хоёр хуудасны Performance, Best Practices болон SEO оноо ижил гарсан. Харин Accessibility үзүүлэлтээр Tailwind илүү өндөр оноо авсан. Ингэснээр CSS framework ашиглан responsive веб хуудас хийх, үр дүнг нь харьцуулах дадлага эзэмшлээ.
